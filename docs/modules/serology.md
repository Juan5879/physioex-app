# Ejercicio 13 — Pruebas serológicas

Fuente: `PHYSIOEX/14_SerologicT/14_SerologicT.swf` (`frame_2/DoAction_2.as`: `DFAMgr`, `ODDMgr`, `ElisaMgr`
y `WBMgr`). Modelo en `model/serology.ts`. Cada experimento es un procedimiento guiado: los pasos se
habilitan en orden, como las secuencias de arrastre del original, y las incubaciones avanzan aceleradas.

- **Anticuerpos fluorescentes directos**: el microscopio muestra 20–28 células y 0, 17–19, 1–3, 19–21 y 0
  cuerpos elementales (A, B, C, +, −). El alumno decide si hay clamidia.
- **Doble difusión de Ouchterlony**: pocillos con cabra anti-caballo, cabra anti-bovino, BSA, HSA y
  desconocido; líneas entre 2–5 (parcial), 2–3 (completa), 3–4 (parcial) y 4–5 (completa). El alumno elige
  la relación de cada par (las parciales muestran un espolón).
- **ELISA indirecto**: DO 1.624 (+), 0.154 (−), 0.054 (A), 0.432 (B) y 1.99 (C).
- **Western blot**: bandas gp160, gp120, p55, p31 y p24 de cada muestra.

Herramienta: Imprimir datos.
